# Security Blog

Blog cá nhân về An toàn thông tin, Web Security, Writeup các phòng Lab (PortSwigger, TryHackMe) và công cụ Pentest.

Website trực tuyến: [https://taind345.github.io/Blog_info_sec](https://taind345.github.io/Blog_info_sec)

Kho ghi chú gốc (Obsidian Vault): [taind345/PortSwigger__TryHackMe__Writeup....etc-](https://github.com/taind345/PortSwigger__TryHackMe__Writeup....etc-)

---

## Nội dung chính

- PortSwigger Web Security Academy (SQL Injection, XSS, SSRF, CORS, Authentication, File Upload)
- TryHackMe & HackTheBox Writeups (Network, Active Directory, CVE Analysis)
- Linux & Hạ tầng mạng
- Công cụ Pentest (Burp Suite, Ffuf, SQLMap, Nmap)
- Kiến thức cốt lõi (Cookie, Session, JWT, SOP, MFA Bypass)

---

## Đặc điểm kỹ thuật

- Sơ đồ tư duy Excalidraw dạng vector SVG tương tác trực tiếp (nhấp link chuyển bài, phóng to/thu nhỏ/kéo thả mượt).
- Font chữ Cascadia Code và font viết tay tiếng Việt DFVN-excalidraw.
- Giao diện tối giản phong cách Notion, hỗ trợ Dark/Light mode.
- Hệ thống liên kết hai chiều (Backlinks) và bản đồ liên kết (Graph View).
- Tự động đồng bộ từ kho Obsidian Vault và triển khai định kỳ qua GitHub Actions.

---

## Lệnh sử dụng

- Chạy thử nghiệm trên máy: `npm run dev` (truy cập `http://localhost:8080`)
- Tự động đồng bộ từ repo gốc và đẩy lên GitHub: `npm run auto-sync`
- Biên dịch trang tĩnh: `npm run build`

Tài liệu chi tiết về kiến trúc hệ thống xem tại [GUIDE_SYSTEM.md](GUIDE_SYSTEM.md).
